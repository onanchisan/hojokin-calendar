# フェーズ1 調査メモ（2026-10-01）

## 確認できた事実（実際にAPIを叩いて確認）

- デジタル庁「Jグランツ」の公開API（`https://api.jgrants-portal.go.jp/exp/v1/public/subsidies`）は認証不要・無料で利用できた。
- キーワード `補助金` で公募中159件、6キーワード統合で重複排除後326件（うち公募中323件）を取得できた。
- 詳細API（`/subsidies/id/{id}`）で、対象地域・上限額・補助率・従業員数・利用目的・対象業種・公式ページURLが取得できる。
- つまり **データ源は無料・無人取得が可能**。ゼロコスト要件を満たす。

## Jグランツ Web-API 利用規約の確認結果（2026-10-01、公式PDF全4ページを読了）

| 論点 | 結果 |
| --- | --- |
| 商用・広告掲載 | **明示的な禁止なし**。第4条は利用者を「補助金の公開情報を基に情報の集計等をする者」としており、情報集計サイトは該当すると解釈できる。ただし広告可否の明記もなく、グレー部分は残る |
| 出典表示 | **必須**（第5条1項）。「出典：Jグランツ」→ 対応済み |
| 加工した旨の表示 | **必須**。「政府公式…jGrants…をもとに〇〇にて作成。政府及び自治体によって保証されたものではありません」→ 全ページのフッターに追加済み。検証スクリプトで欠落を検知 |
| 国が作成したかのような表示 | 禁止 → 対応済み（編集・加工である旨を明記） |
| 第三者の著作権 | 公募要領等に第三者の権利表示がある場合は利用者責任。概要の冒頭抜粋は短く、一次情報へのリンクが主 → 低リスクだが、継続して注意 |
| 大量アクセス・事実に反する内容 | 禁止 → 日次で十数回程度＋差分のみ詳細取得。検証で整合性を確認 |
| ベータ版・突然の停止・規約改定 | あり。停止時は検証で失敗し、古い情報を公開し続けない設計。規約改定は定期的に再確認が必要 |

**結論**：条件付きで利用可。広告の可否に明確な記載がないリスクは残るため、必要ならJグランツ問い合わせ窓口に確認すること。
