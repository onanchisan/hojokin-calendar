見積書・相見積もりの取り方：補助金で金額の根拠を示す方法

補助金の申請では、経費の金額が適切であることを、見積書で示す必要があります。審査する側は、事業者の言い値をそのまま認めるわけにはいきません。見積書は、費用の妥当性を示す根拠です。制度によって必要な枚数や様式は異なるため、公募要領で確認してください。

なぜ複数の見積書が求められるのか

補助金は公的な資金を使うため、「適正な価格で購入しているか」が問われます。一定額以上の経費について、2社以上（または3社以上）の見積書の提出（相見積もり）を求める制度が多くあります。複数社を比べて、もっとも合理的なところを選んだことを示します。

見積書に書かれているべき項目

  • 発行日、有効期限
  • 宛名（申請者名と一致していること）
  • 品名、型番、数量、単価、合計金額
  • 消費税の扱い（税抜か税込か）
  • 発行元の会社名、住所、担当者

「一式」とだけ書かれた見積書は、内訳が不明なため認められないことがあります。内訳の詳しい見積書を依頼しましょう。

相見積もりの進め方

  1. 同じ条件で依頼する：仕様書を作り、各社に同じ内容で見積を依頼する。
  2. 比較表を作る：価格、納期、保証、サポートを並べ、選定の理由を文章でまとめる。
  3. 最安でない場合は理由を書く：性能や納期の違いなど、合理的な理由を説明する。
  4. 日付を守る：見積書の日付は、公募要領が求める期間内か確認する。

よくある不備

  • 見積書の宛名や日付が、条件に合っていない
  • 同一の会社グループなど、関係の深い会社から相見積もりを取っている
  • 見積書の仕様が、事業計画書の説明と一致していない
  • 有効期限が切れている

見積依頼のときの工夫

見積を依頼するときは、「補助金の申請に使う」ことを最初に伝えておくとスムーズです。補助金に慣れた業者であれば、必要な書式や内訳で作成してくれることもあります。また、見積書の有効期限は、審査〜発注までの期間を考えて余裕をもたせてもらいましょう。

提出書類の全体像は、申請前チェックリストも参考にしてください。

比較表のつくり方の例

業務用ソフトの導入について、3社から見積を取った場合の整理例です（架空の例）。

項目A社 / B社 / C社
見積金額（税抜）120万円 / 150万円 / 98万円
主な機能必要機能をすべて満たす / すべて満たす / 一部不足
導入期間2か月 / 1.5か月 / 3か月
サポート電話・メール / 電話・メール・訪問 / メールのみ
選定結果A社を選定。C社は安価だが必要機能が不足。B社はA社より高価で、追加機能は不要。

このように、最安の会社を選ばない場合は、その理由を記述することが重要です。

見積書を取るときの流れ

  1. 仕様書（欲しい機能や数量）をまとめる。
  2. 複数の会社に、同じ仕様書で見積を依頼する。
  3. 返ってきた見積書を、公募要領の条件（日付、宛名、内訳）に照らして確認する。
  4. 比較表を作り、選定理由を書く。
  5. 採択後に、選んだ会社と契約する（交付決定後）。

よくある質問

Q. 見積書の有効期限が切れてしまいました。

採択後の契約時に、改めて見積書を取り直す必要が生じることがあります。審査から契約までの期間を考えて、有効期限は長めに設定してもらうと安心です。

Q. 1社しか対応できない特殊な設備の場合はどうしますか。

1社しか扱えない理由を書いた「理由書」の提出で認められる制度があります。公募要領を確認し、事務局に事前に相談しましょう。

Q. 相見積もりの相手に、補助金の申請と伝えてもよいですか。

伝えて問題ありません。むしろ、補助金に必要な書式や内訳について、協力してもらいやすくなります。
