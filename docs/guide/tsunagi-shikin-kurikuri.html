補助金は後払い：資金繰りと「つなぎ融資」の考え方

補助金の多くは、事業にかかった費用を先に全額支払い、実績報告のあとに補助金が入金される「精算払い（後払い）」です。補助率が2/3や1/2でも、一度は全額を立て替える必要があります。資金繰りを見誤ると、採択されても事業を進められなくなります。

資金が必要な期間のイメージ

時期お金の動き
交付決定後〜事業実施設備代・外注費などを支払う（全額が先に出ていく）
実績報告の提出報告書類を作成して提出する
確定検査〜入金書類の確認後、補助金額が確定して入金される

支払いから入金まで、半年から1年程度かかることもあります。

具体例で考える

1,200万円の設備を導入し、補助率2/3（補助金額800万円）の場合、いったん1,200万円を支払い、のちに800万円が入金されます。自己負担は最終的に400万円ですが、その間は1,200万円分の資金が必要です。

資金を用意する方法

  • 自己資金：手元資金から支払う。もっとも単純だが、運転資金が不足しないか注意する。
  • つなぎ融資：補助金の入金までの資金を、金融機関から借りる。補助金が入金されたら返済する。
  • 分割払い・リースなど：制度によっては対象外の場合がある。公募要領で確認する。
  • 公的な融資制度：日本政策金融公庫や信用保証協会付きの融資など。

つなぎ融資を相談するときのポイント

  1. 採択後に相談を始める：交付決定通知が、融資の審査に使われることが多い。
  2. 金融機関に事前に相談する：取引のある金融機関に、補助金の採択予定を伝えておく。
  3. 返済計画を立てる：補助金の入金が遅れた場合の対応も考えておく。

注意したいこと

  • 補助金は不採択のリスクがあるため、採択前に大きな支出をしない。
  • 入金時期は計画より遅れることがあるので、余裕をもたせる。
  • 確定した補助金額が、申請時の想定より少なくなることがある（対象外経費が見つかった場合など）。

全体の流れは申請の流れの記事も参考にしてください。

資金繰り表のつくり方

補助金を使う事業では、月ごとの入出金を一覧にした資金繰り表をつくっておくと安心です。簡単な例を示します（架空の例、単位：万円）。

月1月 / 2月 / 3月 / 4月 / 5月 / 6月 / 7月
通常の収入300 / 300 / 300 / 300 / 300 / 300 / 300
通常の支出280 / 280 / 280 / 280 / 280 / 280 / 280
補助事業の支払い0 / 0 / 600 / 0 / 0 / 0 / 0
補助金の入金0 / 0 / 0 / 0 / 0 / 0 / 400
月末の残高（概算）20増 / 40増 / 540減 / 520減 / 500減 / 480減 / 80増（補助金入金後）

この例では、3月から6月にかけて残高が大きくマイナスになります。補助金の入金までの資金が不足する時期を見つけ、つなぎ融資や自己資金で埋める計画をつくりましょう。

金融機関に相談するときに伝えること

  • 補助金の名称、採択の状況、交付決定額
  • 事業の内容と、補助金の入金予定時期
  • 返済の計画と、返済の原資
  • 補助金が入金されなかった場合の対応

よくある質問

Q. 補助金の入金が遅れると、どうなりますか。

入金の時期は、確定検査の進み具合で変動します。つなぎ融資の返済期限には余裕を持たせ、必要に応じて延長を相談できるようにしておきましょう。

Q. 概算払いが認められる制度はありますか。

事業の途中で、一部の補助金が先に支払われる「概算払い」を設けている制度もあります。公募要領で確認してください。
